Who I Am

I'm Kshitij — a CS student in Nepal working toward a career in security research and exploit development. Self-taught, working independently: no bootcamp, no structured course — just building things until I understand them, then breaking them to understand deeper.

What I Work On

  • Network protocol implementation — built a C shared library (libmylib) implementing Ethernet, ARP, IPv4, UDP, and DNS from scratch — including Internet checksums, raw socket management, and frame parsing/crafting byte by byte
  • Binary analysis — ELF parser that reads section headers, program headers, type mappings, and the string table directly from the binary format without using libelf
  • Assembly programming — wrote a working HTTP server in pure x86-64 Intel-syntax assembly: no libc, no C runtime, just syscalls — handles GET/POST, forks per client, serves files (from a pwn.college challenge, extended independently)
  • Exploit development & security scripting (learning) — actively working through pwn.college; hands-on experience overwriting return addresses, exploiting format-string memory leaks with pwntools, analyzing x86-64 calling convention register exhaustion, and building raw socket tooling
  • Cryptography attacks — AES-ECB byte-at-a-time oracle, CBC bit flipping, RSA signature forgery
  • Network tools — packet sniffer and ARP frame crafter built on top of libmylib, dissecting live traffic at the Ethernet frame level

Tools I Actually Use

Where I Practice

Actively working through pwn.college — binary exploitation, shellcoding, reverse engineering. The writeups on this site come directly from that work.

Where This Is Going

The long-term goal is security research and exploit development — vulnerability research, binary exploitation, and contributing to autonomous vulnerability discovery. Everything on this site is a step toward that, documented honestly as it happens.
