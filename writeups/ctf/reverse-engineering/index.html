What Is Reverse Engineering

Reverse engineering is the art of decompiling a binary file using various reverse engineering techniques and tools to understand the intent of the program.

Binary File Structure

A binary file is just a bunch of binary data, which usually contains a header describing the overall structure a loader needs before it can be turned into a process. The header typically contains a magic number identifying the file format type.
