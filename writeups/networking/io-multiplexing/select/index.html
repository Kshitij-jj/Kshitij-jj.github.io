select()

Monitoring multiple file descriptors using I/O multiplexing

⬅ I/O Multiplexing

Introduction

select() is a classic I/O multiplexing system call that allows one thread to monitor multiple file descriptors.

Syntax

#include <sys/select.h>

int select(
    int nfds,
    fd_set *readfds,
    fd_set *writefds,
    fd_set *exceptfds,
    struct timeval *timeout
);

Parameters

Parameter Description
nfds Highest file descriptor number + 1.
readfds Descriptors monitored for reading.
writefds Descriptors monitored for writing.
exceptfds Descriptors monitored for errors.
timeout Maximum time select() waits.

FD_SET Macros

FD_ZERO()
FD_SET()
FD_CLR()
FD_ISSET()
  • FD_ZERO() clears a set.
  • FD_SET() adds a descriptor.
  • FD_CLR() removes a descriptor.
  • FD_ISSET() checks readiness.

Workflow

  1. Create sockets.
  2. Add descriptors into fd_set.
  3. Call select().
  4. Check ready descriptors.
  5. Handle ready sockets and repeat.

Advantages

  • Single thread handles multiple clients.
  • Reduces CPU usage.
  • Avoids busy polling.
  • Portable across Unix-like systems.

Limitations

  • Limited by FD_SETSIZE.
  • Not efficient for huge numbers of connections.
  • fd_set must be rebuilt every loop.
  • Uses linear scanning.
