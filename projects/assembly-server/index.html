Assembly HTTP Server

x86-64 · Intel syntax · no libc · Linux syscalls only

⬡ View on GitHub

About

An HTTP/1.1 web server written in pure x86-64 Intel-syntax assembly — no libc, no C runtime, no compiler, no abstractions. Every instruction written by hand.

Started as a pwn.college dojo challenge. Kept going because writing a server in assembly forces you to understand what every single byte does. There is no wrapper to hide behind.

What It Does

  • Handles GET and POST requests over HTTP/1.1
  • Forks a child process per client connection using the fork syscall
  • Serves files from disk — reads them via open/read/write syscalls
  • Writes POST bodies to disk
  • Does all this with zero external dependencies — just the Linux kernel

What It Required Knowing

  • Linux syscall ABI — arguments in rdi, rsi, rdx, r10, r8, r9; return in rax; syscall instruction
  • Socket syscalls — socket, bind, listen, accept, recv, send, close
  • Process management — fork, wait4, exit
  • File I/O — open, read, write at the syscall level
  • x86-64 register layout — caller/callee-saved registers, stack alignment
  • ELF binary structure — to produce a valid standalone executable without a linker script from scratch
  • HTTP/1.1 wire format — parsing request lines and headers by byte inspection

Why This Matters for Security

Writing a server in assembly develops the same mental model needed for exploit development:

  • You think in bytes, not types
  • You know exactly what's on the stack at every moment
  • You understand what a call and ret actually do at the machine level
  • You can read disassembly of any compiled binary because you've written the equivalent by hand

A Real Code Snippet

; sys_write(fd, buf, len)
; rdi = fd, rsi = buf, rdx = len
sys_write:
    mov rax, 1          ; SYS_write
    syscall
    ret

; sys_fork()
sys_fork:
    mov rax, 57         ; SYS_fork
    syscall
    ret

; accept(sockfd, NULL, NULL) -> client_fd
.accept_loop:
    mov rdi, [sockfd]
    xor rsi, rsi        ; addr = NULL
    xor rdx, rdx        ; addrlen = NULL
    mov rax, 43         ; SYS_accept
    syscall
    test rax, rax
    js .accept_loop     ; retry on error
    mov [client_fd], rax
