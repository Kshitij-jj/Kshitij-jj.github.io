neurocrawl

C · web crawler · OSINT · reconnaissance · in design

⬡ View on GitHub

Status

⚠️ This project is currently in the design and architecture phase. No working implementation yet — but the design is solid enough to be worth documenting.

What It Will Be

A high-performance web crawler written in C, designed for OSINT and reconnaissance workflows. Starting from a seed URL, it traverses links using BFS, extracts structured data, and pipes output to analysis layers.

Planned Architecture

  • Crawler core — BFS link traversal using a queue, written in C for performance
  • HTTP client — raw socket-based HTTP/1.1 requests (building on libmylib network primitives)
  • HTML parser — lightweight link extraction without full DOM parsing
  • OSINT layer — extract emails, subdomains, metadata, and structured data from pages
  • Output — structured JSON for downstream analysis pipelines

Why C

  • Performance — crawling at scale means thousands of connections; C gives full control over memory and I/O
  • Fits the existing toolset — built on the same raw socket and network primitives as libmylib
  • No runtime overhead — no GC, no VM, no interpreter

Why This Project

OSINT and reconnaissance are foundational to offensive security. Most crawlers are Python or Go — understandable, but not educational at the systems level. Building this in C forces understanding of connection management, buffer handling, and protocol implementation that higher-level tools hide.
