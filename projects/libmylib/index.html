libmylib

C shared library · raw network programming · Linux

⬡ View on GitHub

About

libmylib is a C shared library (libmylib.so) that provides a clean, low-level API for raw network programming on Linux. Built while learning how the TCP/IP stack actually works — not calling high-level socket wrappers, but implementing protocols byte by byte above a raw packet socket.

Building this required reading RFCs, understanding network byte order, implementing the Internet checksum algorithm, and managing raw AF_PACKET sockets directly.

What It Implements

  • Byte-order helpers
    • net_get16 / net_put16 — read/write 16-bit big-endian values
    • net_get32 / net_put32 — read/write 32-bit big-endian values
  • Debug tools
    • net_hexdump() — formatted hex + ASCII dump of any buffer
    • net_mac_to_str() / net_str_to_mac() — MAC address conversion
  • Raw socket
    • net_raw_open(ifname) — opens an AF_PACKET / SOCK_RAW socket bound to a named interface
  • Ethernet (Layer 2)
    • net_eth_build() / net_eth_parse() — builds and parses Ethernet II frames
  • ARP
    • net_arp_build() / net_arp_parse() — ARP request/reply builder and parser with full field validation
  • IPv4 (Layer 3)
    • net_ip_build() — builds IPv4 headers with TTL, DF flag, and computed Internet checksum
    • net_ip_parse() — validates version, IHL, checksum, extracts protocol/addresses
    • net_checksum() — RFC 1071 Internet checksum (one's complement sum)
  • UDP (Layer 4)
    • net_udp_build() / net_udp_parse() — full UDP segment construction and validation including pseudo-header checksum
  • DNS
    • net_dns_encode_name() / net_dns_build_query() — DNS wire-format name encoding and query construction
  • Error handling
    • ml_err_exit() / ml_warn() — consistent error reporting

A Real Code Snippet

u8 *net_ip_build(u8 *buf, u16 payload_len, u8 protocol,
                 const u8 *src_ip, const u8 *dst_ip)
{
    buf[0] = (IP_VERSION << 4) | IP_IHL_MIN; /* 0x45 */
    buf[1] = 0;                              /* TOS  */
    net_put16(buf + IP_OFF_TOTLEN, IP_HDR_LEN + payload_len);
    net_put16(buf + IP_OFF_ID,     0x1234);
    net_put16(buf + IP_OFF_FLAGS,  IP_FLAG_DF);
    buf[IP_OFF_TTL]   = IP_TTL_DEFAULT;
    buf[IP_OFF_PROTO] = protocol;
    net_put16(buf + IP_OFF_CSUM, 0);         /* zero before checksum */
    memcpy(buf + IP_OFF_SRC, src_ip, IP_ADDR_LEN);
    memcpy(buf + IP_OFF_DST, dst_ip, IP_ADDR_LEN);
    net_put16(buf + IP_OFF_CSUM,             /* compute last */
              net_checksum(buf, IP_HDR_LEN));
    return buf + IP_HDR_LEN;                 /* pointer to payload */
}

What This Taught Me

  • How to read RFCs and translate wire format into C structs
  • The Internet checksum algorithm (RFC 1071) — one's complement sum with carry folding
  • AF_PACKET / SOCK_RAW socket programming on Linux
  • Network byte order and manual big-endian field construction
  • Modular C library design and building shared objects with gcc -shared
