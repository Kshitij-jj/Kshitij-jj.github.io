ELF Parser

Binary analysis tool · C · no libelf · raw file I/O

⬡ View on GitHub

About

A command-line ELF binary parser written in C. Pass it any ELF binary and it dumps the full header, section headers, section types, flags, addresses, and names — similar to readelf -a, but implemented from scratch without libelf.

Reads the binary directly using open, read, and lseek — no library abstractions.

What It Parses

  • ELF Identification (e_ident)
    • Magic bytes (0x7f 0x45 0x4c 0x46)
    • Architecture class (32-bit / 64-bit)
    • Data encoding (little-endian / big-endian)
    • OS/ABI (System V, Linux, FreeBSD, ARM, etc.)
  • ELF Header
    • File type (ET_EXEC, ET_DYN, ET_REL)
    • Machine architecture (x86, x86-64, ARM, AArch64, RISC-V, etc.)
    • Entry point address
    • Program/section header offsets
  • Section Headers (all of them, by name)
    • Section type (PROGBITS, SYMTAB, STRTAB, RELA, DYNAMIC, etc.)
    • Flags (Writable, Allocatable, Executable)
    • Load address, file offset, size
    • Section names resolved via the string table (.shstrtab)

What This Taught Me

  • The ELF binary format specification (ELF64 header layout, section/program header tables)
  • How lseek + read navigates binary file structures
  • How section names are stored as offsets into the .shstrtab string table
  • How readelf and objdump do what they do — now I know, because I wrote it
  • This is the foundation for understanding how exploits target specific sections (.text, .plt, .got)

Why This Matters for Security

Understanding the ELF format is prerequisite knowledge for binary exploitation. When you're doing ret2libc, ROP, or GOT overwrites — you're navigating ELF structures. This parser was built to internalize that knowledge, not just use tools that abstract it away.
