CRecon

A TCP Port Scanner in C

⬅ Back to Projects

About

CRecon is a lightweight TCP port scanner written in pure C. It is built as part of a journey into cybersecurity and low-level network programming.

It resolves hostnames using DNS, performs TCP connect scans using raw sockets, and classifies ports as OPEN, CLOSED, or FILTERED, similar to tools like Nmap.

What This Project Taught

  • Raw socket programming in C
  • DNS resolution using getaddrinfo()
  • TCP connect-based scanning technique
  • Network reconnaissance fundamentals
  • Memory management and modular C design

Features

  • Scan single or multiple targets (IP or hostname)
  • Automatic DNS resolution to multiple IPs
  • Port classification: OPEN / CLOSED / FILTERED
  • Custom port ranges via -p flag
  • Clean scan reports per target

Usage

# Single target
./crecon 192.168.1.1

# Multiple targets
./crecon google.com 192.168.1.1

# Specific ports
./crecon 192.168.1.1 -p 80 443

# Port range
./crecon 192.168.1.1 -p 1-1024

Tech Stack

  • C (POSIX standard)
  • TCP sockets
  • Linux system calls

How It Works

CRecon uses TCP Connect Scanning, similar to nmap -sT.

  • Create TCP socket per port
  • Attempt connection to target IP:port
  • Classify result based on response
CONNECT SUCCESS → OPEN
ECONNREFUSED    → CLOSED
TIMEOUT         → FILTERED
